# SQL Queries & Functions

Practicing SQL queries and functions on a MySQL database (`practice_db`), with questions, solutions, and Workbench result screenshots.

## Database Tables
- `departments`
- `employees`
- `customers`
- `products`
- `orders`

## Topics Covered
- **SELECT**: retrieving all or specific columns
- **WHERE**: filtering with comparison operators, AND, and LIKE
- **ORDER BY**: sorting ascending and descending
- **NULL filtering**: finding missing values with IS NULL
